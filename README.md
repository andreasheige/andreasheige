# Hi, I'm Andreas 👋

I started out building websites. Then I got curious about everything that
happens after you press "deploy": the pipelines, the infrastructure, the
security. That pulled me through DevOps and DevSecOps, and eventually into
developer experience, where the question became *why is this so hard for
everyone else on the team?*

Then AI coding agents showed up, a new kind of teammate: fast, tireless and
confidently wrong in brand-new ways. So the DevEx question changed again:
how do you build the *harness* around them? The instructions, specialised
agents, reusable skills, shared memory, hooks and quality gates that make an
agent behave like a good colleague instead of an eager intern who skips the
tests.

Now I'm following the same curiosity one layer deeper: how do machines
actually learn? I'm working it out the way I learned everything else, by
building something small, breaking it, and writing down what I find.

The thread through all of it hasn't changed: build things that work reliably,
then make them easy for other people to build on. So the ML gets the same
treatment as any production system: tests, CI, reproducibility.

I'm a senior engineer at Knowit in Gothenburg.
